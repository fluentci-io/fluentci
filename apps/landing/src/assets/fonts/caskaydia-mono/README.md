# CaskaydiaMono

Regular and Bold Mono fonts from [Nerd Fonts v3.5.1](https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1), converted losslessly from TTF to WOFF2 with `woff2_compress` for self-hosting on the landing site.

Source archive: [CascadiaMono.tar.xz](https://github.com/ryanoasis/nerd-fonts/releases/download/v3.5.1/CascadiaMono.tar.xz).
