# Imported Studio source

Source: https://github.com/fluentci-io/fluentci-studio
Commit: 6d34f3fe940709d36bb7767b6d705df2f00ca794

The original imported hosted application has been replaced with a local-first
Studio built with React, Tailwind CSS, Jotai, and TanStack Query. It is embedded
directly into FluentCI and uses the CLI's Axum GraphQL and WebSocket endpoints.
The hosted authentication, billing, marketplace, visual pipeline editor, and
legacy styling/state providers have been removed. The source's MPL license is
retained in LICENSE.
